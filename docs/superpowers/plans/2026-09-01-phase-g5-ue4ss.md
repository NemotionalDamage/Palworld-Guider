# Phase G5 UE4SS Read-Only Chat Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the approved authenticated loopback UE4SS adapter path that captures `!guide ` chat questions and returns concise grounded replies without gameplay mutation.

**Architecture:** A new `game-gateway` crate provides the schema-2 authenticated loopback WebSocket contract. A new `guide-adapter` crate intersects adapter capabilities with the Guider allowlist, exposes the two verified read tools to the existing `GuideAgent`, and owns the bounded in-game chat loop. A renamed transport-only native shim plus Lua adapter implement the same protocol under `adapter/read-only/ue4ss/`.

**Tech Stack:** Rust stable, Axum, Tokio blocking execution, the existing Rust guide core, `tungstenite` protocol tests, UE4SS Lua, MSVC C++20, WinHTTP, CMake/Ninja.

**Spec:** `docs/superpowers/specs/2026-09-01-phase-g5-ue4ss-design.md`

## Global Constraints

- Execute only Phase G5 UE4SS work; add no private-server REST request path.
- Target local single-player Steam Palworld App `1623730`, build `24575825`, UE4SS `3.0.1 Beta #0` SHA `d935b5b`.
- Approved client reads are only player position and active-Otomo identity/position.
- Bind only literal `127.0.0.1`; bearer tokens come only from environment variables and are never logged or committed.
- Limit text frames to 65,536 bytes and queues to 64 messages.
- Allow one active authenticated adapter session; replacement cancels pending calls and clears old capabilities.
- Chat prefix is exactly `!guide `; empty instructions are ignored.
- Do not copy or register `body-control`, movement, combat, gathering, construction, inventory mutation, world mutation, raw-save reading, arbitrary file paths, shell commands, or SQL.
- `send_chat_message` is internally dispatchable for final replies but never model-visible.
- Back up world `3C2BA10146F65256FD1B889FBF5F854F` to `.local/backups/g5/3C2BA10146F65256FD1B889FBF5F854F/`, retain 30 days, and verify the backup before adapter installation.
- Run each task's focused test and `git diff --check` before every commit.
