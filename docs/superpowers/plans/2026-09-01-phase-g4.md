# Phase G4 State-Aware Advisor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Combine reviewed knowledge, explicit read-only player state, and preferences into deterministic prioritized advice.

**Architecture:** `state-snapshot` validates and summarizes explicit snapshots without runtime I/O. `guide-planner` reuses `GuideEngine` calculators and knowledge relationships to analyze state and rank a bounded advice set. `guide-tools` and `guide-agent` expose typed, redacted planner tools while keeping the raw snapshot outside model input.

**Tech Stack:** Rust stable, existing `game-knowledge`, `guide-core`, `knowledge-index`, `guide-tools`, and `guide-agent`, serde/serde_json, deterministic integration tests.

**Spec:** `docs/superpowers/specs/2026-09-01-phase-g4-design.md`

## Global Constraints

- Execute G4 only; no game observer, save parser, server API, UE4SS adapter, file watcher, or mutation path.
- Dynamic state is explicit, user-entered, read-only, and off by default.
- Raw snapshots and save files are never sent to the model.
- Facts and calculations come from reviewed knowledge and existing deterministic Rust calculators.
- Unknown, stale, incomplete, conflicted, and adversarial inputs remain explicit.
- Recommendations are deterministic and return three to five steps when sufficient evidence exists.
- Run `cargo fmt --all -- --check`, `cargo clippy --all-targets -- -D warnings`, `cargo test`, and `git diff --check` before completion.
