# Reference Intake Template

Use one section per supplied source.

```text
Source title:
Supplier:
Retrieved date:
URL or local path:
Claimed Palworld version:
Scope:
Format:
Reliability concerns:
Initial confidence:
Reviewer:
Review result:
Facts extracted:
Conflicts found:
Follow-up needed:
```

## Field Rules

- `Claimed Palworld version` must remain `unknown` if the source does not state or imply one.
- `Scope` should identify whether the source covers items, recipes, Pals, drops, mechanics, progression, or mixed content.
- `Reliability concerns` should mention missing dates, unclear patches, community edits, contradictions, or commercial spam.
- `Facts extracted` should list normalized fact IDs, not long copied text.
- `Conflicts found` must reference the other source IDs.
