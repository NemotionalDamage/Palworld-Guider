# Reference Data

This directory tracks sources used to build the reviewed knowledge base.

Before using a supplied page, dataset, video, spreadsheet, or guide:

1. add it to `source-log.md`
2. record its claimed Palworld version
3. record the retrieval date and supplier
4. note its scope and limitations
5. normalize required facts into a future reviewed dataset
6. record any conflicts separately

No detailed source has been registered yet.
