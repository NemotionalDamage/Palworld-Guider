# Palworld Guider

Palworld Guider is a read-only in-game advisor that helps players understand items, materials, Pals, crafting, and progression without switching to a wiki.

The project is guide-first rather than automation-first. It will provide:

- factual explanations from a versioned knowledge base
- state-aware material and goal-gap analysis
- concise next-step recommendations
- an in-game chat interface once the offline guide is reliable

The current repository contains the project charter and reference-data policy. No game data has been reviewed yet.

## Development Path

1. **G0** — project charter and reference baseline
2. **G1** — knowledge schema and reviewed source intake
3. **G2** — offline guide MVP
4. **G3** — state-aware advisor
5. **G4** — progression planner
6. **G5** — integrated chat guide
7. **G6** — knowledge maintenance and hardening

See `PHASES.md` for current progress and `AGENTS.md` for the governing specification.
